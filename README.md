# 小隊抽獎系統

十個小隊，隨機抽出前往的地點。純前端、可離線（PWA）、可加到手機主畫面。

## 線上網址

部署於 GitHub Pages：`https://glade9001.github.io/team-lottery/`

## 地點與名額

| 地點 | 名額 |
|------|------|
| 中街 | 2 |
| 溪湖糖廠 | 3 |
| 東螺溪 | 3 |
| 葡萄園 | 2 |

合計 10 組，對應十個小隊。

## 功能

- 每個小隊抽一次，轉盤動畫後分配地點，名額滿的地點不會被抽到。
- 即時顯示各地點剩餘名額與已分配小隊。
- 資料存於瀏覽器 localStorage，重整不消失（換裝置／清快取會重來）。
- **離線可用**：第一次連網開啟後，Service Worker 會快取，之後無網路也能抽。

## 後台

右上角 ⚙️ 進入，預設密碼 `0000`（改 `index.html` 內 `ADMIN_PWD`）。
可指定某小隊固定抽到指定地點（轉盤照跑、外觀看不出來）。

## 更新離線快取

改動 `index.html` 等檔案後，把 `sw.js` 裡的 `CACHE` 版本號 +1，使用者重新連網開啟即會更新。
